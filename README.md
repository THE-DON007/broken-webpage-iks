# Responsive Layout Debugging

A responsive web layout debugging project completed as part of the I-NNOVA Kickstarter Accelerator.

## What I Fixed

* Fixed navigation overlap caused by absolute positioning and fixed offsets.
* Fixed horizontal scrolling caused by a fixed-width banner.
* Made the banner responsive using `width: 100%` and `max-width`.
* Made card headings responsive using `clamp()`.
* Improved the layout for mobile, tablet, and desktop screen sizes.

## Tools Used

* HTML
* CSS
* Firefox Developer Tools
* Git & GitHub
* GitHub Pages

## Debugging Process

I used Firefox Developer Tools to inspect the broken elements before changing the code. I identified the CSS rules responsible for the layout problems, fixed the root causes, and then tested the page across different screen sizes.

## Key Lesson

This activity helped me understand that effective debugging is not just about fixing what looks wrong. It is about identifying the underlying CSS rule causing the problem and testing the solution across different screen sizes.
